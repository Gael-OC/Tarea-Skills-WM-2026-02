Si la foto se sube, la API valida JPEG, PNG o WebP de hasta 2 MB y guarda sus bytes y su tipo. Si se entrega una URL o ruta, guarda esa dirección. La API devuelve una URL corta para servir una imagen almacenada.

EL RECORRIDO COMPLETO

De la pantalla a la base

01 · Enviar

Angular envía los datos y la foto a la API de FastAPI.

02 · Guardar

La API valida, relaciona los datos y confirma la escritura en PostgreSQL.

03 · Mostrar

La API consulta las tablas, calcula los totales y devuelve JSON para la pantalla.

Los identificadores y el registro de este recorrido son un ejemplo ilustrativo. La tabla seguimientos completa el modelo y permite construir el feed.
